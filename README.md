# 🚀 AI-Powered Document Generation Workflow (n8n)

An end-to-end automated workflow built with **n8n** that streamlines corporate agreement creation. The system captures client inputs through an n8n Form Trigger, leverages an **AI Agent (powered by Google Gemini 3.1 Flash Lite)** to draft a formal Scope of Work (SOW) and Agreement, generates and updates a **Google Doc**, configures public sharing permissions via **Google Drive**, and sends a stylized HTML notification via **Gmail**.

---

## ✨ Key Features

- **Dynamic Form Intake:** Captures client details including *Client Name*, *Service Type*, *Contract Value (USD)*, *Project Scope*, and *Recipient Email*.
- **AI-Driven Legal Drafting:** Uses **Gemini 3.1 Flash Lite** to compile formal SOW agreements featuring standard legal sections (Overview, Scope, Financial Terms, Confidentiality, Signatures).
- **Automated Currency Formatting:** Ensures the provided contract value is formatted as standard USD currency (e.g., $4,500.00 USD).
- **Automated Google Docs Management:** Programmatically creates a dedicated file in Google Drive and populates it with structured output.
- **Drive Permission Handling:** Automatically configures document sharing settings to `reader` access for `anyone` to eliminate access barriers.
- **Responsive HTML Email Delivery:** Sends professional, branded HTML notification emails containing a direct action button to view the document.

---

## 📋 Input Form Specifications

The `formTrigger` node requests the following inputs:

| Field Label | Field Type | Required | Options / Details |
| :--- | :--- | :---: | :--- |
| **Client Name** | Text | Yes | Name of the client or organization |
| **Service Type** | Dropdown | Yes | `AI & Workflow Automation`, `Commercial Real Estate Consulting`, `Custom Agent Development`, `CRM Integration & Management` |
| **Contract Value (USD)** | Number | Yes | Numeric contract amount (Formatted to USD by AI) |
| **Project Scope & Details** | Text Area | Yes | High-level project specifications and deliverables |
| **Recipient Email** | Email | Yes | Email address where the document link is delivered |

## 🔧 Prerequisites & Credentials

To deploy this workflow in your n8n instance, ensure you have configured credentials for:

1. **Google Gemini / PaLM API** (`@n8n/n8n-nodes-langchain.lmChatGoogleGemini`) configured with **Gemini 3.1 Flash Lite** (`models/gemini-3.1-flash-lite`)
2. **Google Docs OAuth2 API** (`n8n-nodes-base.googleDocs`)
3. **Google Drive OAuth2 API** (`n8n-nodes-base.googleDrive`)
4. **Gmail OAuth2 API** (`n8n-nodes-base.gmail`)

---

## 🚀 How to Import and Setup

1. **Download Workflow JSON:** Save the `AI_Powered_Document_Generation.json` file from this repository.
2. **Import into n8n:**
   - Open your n8n canvas.
   - Click on **Workflow** menu $\rightarrow$ **Import from File** or paste the JSON content.
3. **Configure Credentials:**
   - Select your **Google Gemini API** account inside the *Google Gemini Chat Model* node (ensuring the model is set to `models/gemini-3.1-flash-lite`).
   - Connect your OAuth2 credentials for *Google Docs*, *Google Drive*, and *Gmail* nodes.
4. **Set Google Drive Folder:**
   - Open the `Create a document` node and verify/update your target Google Drive `folderId`.
5. **Activate Workflow:**
   - Toggle the workflow state from `Inactive` to `Active`.
   - Open the Form URL generated by the `On form submission` node to test the setup.
